# Bounded structural whitespace for the pinned native tool parser

This optional adapter addresses observed unfinished tool arguments containing thousands of formatting spaces. It is pinned to vLLM 0.27.1 and XGrammar 0.2.3. It subclasses the existing `Qwen3EngineToolParser`; native tool extraction is inherited unchanged.

The adapter converts the original structural tag to EBNF using XGrammar's supported API, scans that generated grammar, and narrows only unbounded `[ \n\t]*` formatting atoms outside quoted literals and other character classes to `{0,2}`. It then round-trips the result through `Grammar.from_ebnf` and `GrammarFormat`. JSON/XML syntax, property order, required fields, enums, types, quoted string contents, and tool wrappers remain the original grammar. Unexpected versions or missing expected atoms fail closed. This is a version-specific transformation, not a universal grammar normalizer.

Six CPU tests ran inside the pinned image. The initial implementation accepted the 1,000-space regression; the adapter rejects it. Tests also preserve the actual assessment schema's constraints, Unicode, negation, literal multiple spaces, and upstream native extraction. `current-assessment-schema.json` is copied from the initial request in `fixtures/results/2026-11-08-production-brev-baseline.json`; it contains schemas only, no caller transcript. Run `python3 -m unittest -v test_compact_tools` with this directory as the working directory inside the pinned image and its cached checkpoint tokenizer available. These tests do not establish model accuracy or phone behavior.

Enable only with `FIRSTRING_COMPACT_TOOL_GRAMMAR=1` for `serve.sh`, with the hash-matching plugin at `$FIRSTRING_NEMOTRON_DIR/firstring_compact_tools.py`. The default remains upstream `qwen3_coder`. `restart-compact.sh` requires the active shutdown guard, preserves caches, and retains the original stopped container. It never allocates compute or alters the cleanup deadline. Rust's strict native validation, token budget, time limits, and retained token-15 stop boundary remain unchanged.

Primary references: [XGrammar 0.2.3 grammar APIs](https://github.com/mlc-ai/xgrammar/blob/v0.2.3/python/xgrammar/grammar.py), [vLLM 0.27.1 tool-parser hooks](https://github.com/vllm-project/vllm/blob/v0.27.1/vllm/tool_parsers/abstract_tool_parser.py), and [documented custom parser registration](https://docs.vllm.ai/en/v0.27.1/features/tool_calling/#custom-tool-parsers).
